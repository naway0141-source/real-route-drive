# REAL ROUTE 3D DRIVE

実在の地名を入れると、実際の道路ルートと街並みで走れる3Dバーチャルドライブ。Gemini が作成した単一 HTML ファイル作品を、風景生成まわりを手直しして公開しています。

## 仕組み

- 地名検索: Nominatim（OpenStreetMap）
- ルート: OSRM（実在の道路ネットワーク）
- 標高: Open-Meteo Elevation API
- 風景: Overpass API（OpenStreetMap の建物・土地利用・水域データ）
- 描画: Three.js / サウンド: Tone.js（いずれも CDN 読み込み、`index.html` 1ファイル完結）

## 手直し内容（タマ版）

- 風景データの取得をルート沿いの区間ごとに分割し、失敗した区間だけ取り直す方式に変更（一部の区間が取れればその分は描画される）
- 建物を中心点の箱ではなく、地図データの輪郭（フットプリント）どおりの形で立体化
- 田畑・住宅地・森林・水域を実物のポリゴン形状で描画（印旛沼のような湖沼も面として表示）
- 実データで田畑・水域の場所には、沿道の補完住宅を置かないように抑制

## 遊び方

- 出発地・目的地（経由地も可）を入力してルートを構築すると走行開始
- おすすめプリセット: 「佐倉駅 → 印旛沼サンセットヒルズ」ほか
- 操作は画面表示に従ってください（自動クルーズあり）
